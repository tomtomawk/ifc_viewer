# Suivi : fait et abandonné

**Journal du projet.** Ce qui est fait et ce qui est abandonné s'écrit ici ; ce qui reste à faire est dans [ROADMAP.md](ROADMAP.md). Les autres documents décrivent le fonctionnement ; ils ne portent ni « fait », ni « à faire », ni avancement.

Règles de tenue :

1. Tout commit ajoute une ligne en tête du Journal (§3) : date, ce qui a été fait, commit, vérification réellement faite. Ce qui n'a pas été vérifié est écrit tel quel (« non essayé à l'écran »).
2. La colonne Commit porte le hash court du commit qui livre le travail ; comme une ligne ne peut pas citer le commit qui l'ajoute, écrire `ce commit` et laisser le hash se lire dans `git log -- docs/SUIVI.md`, ou compléter la ligne au commit suivant.
3. Une tâche abandonnée entre au §2 avec la date et la raison, et quitte [ROADMAP.md](ROADMAP.md) dans le même commit.
4. Le suivi se met à jour dans le même commit que le code.
5. Les journaux détaillés d'anciens chantiers (`docs/historique/`, cités plus bas) ont été supprimés le 20/11/2026 ; ils se lisent par `git show 9121974:docs/historique/<fichier>`.
